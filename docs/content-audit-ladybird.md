# 七星瓢虫第二批内容核校

核对日期：2026-10-01。对象为 `ladybird` / *Coccinella septempunctata*。本轮核对列举断言及相关中英文课程，未做昆虫学专家复审，也未证明整物种所有内容正确。

## 断言对应与修改

| 字段/原断言 | 处理与依据 |
| --- | --- |
| summary、食性、课程：“几乎只吃蚜虫”及特定蚧壳虫/粉虱名单 | S1支持更广的猎物范围。保留蚜虫为主要猎物，改为也捕食其它小型昆虫及其卵，不引入新的固定食谱。 |
| 体长5–8毫米，“中等偏小” | S2资料记7–8毫米且形容相对较大。改为注明大学资料口径的约7–8毫米，删体型等级评价；不宣称5毫米个体不存在。 |
| “温暖地区一年多代” | 本轮未建立全分布区依据。采用S2明确的美国东北部1–2代与成虫越冬，详情和课程都保留地区。 |
| 幼虫发育期间捕食数百只 | 没有本轮实际读取的带条件测量依据。该事实行改为幼虫与成虫均能捕食，不把未知数字当作错误，也不换用其它物种的数字。 |
| 防御、腿部热点和课程 | S4支持腿关节反射性出血和防御生物碱。删去本轮未由该摘要核实的颜色、固定量和刺激性描述。 |
| “只有七星瓢虫恰好七个斑点”；同属近缘种从2到20多点 | 删排他性结论及“同属”数量范围。S1/S3/S5支持通常七枚及结合其它形态辨认；课程说明斑点分布，测验解释同步修正。 |
| “鸟尝一次就永久回避” | 未建立个体学习次数与永久回避证据。保留警戒色与化学防御关系，删除固定一次学习的叙述。第一道测验改为有S4直接依据的防御体液。 |
| 头部能整个缩入 | 未由所读原文核实。改为S1/S2的头部浅色斑形态。 |
| 触角专门探测蚜虫蜜露气味 | 未建立这种特定线索的对应。改为S1短棒状触角形态，不把一般化学感知当作该特定机制证据。 |

| 原产欧亚及北非 | 本轮明确核对欧亚和北美引入。改“原产分布包括欧亚”，不是完整全球范围清单；未证明北非不存在。 |
| “常见、广泛生防资源” | S3支持北美常见的引入种群，改为该地域描述；不由常见度推导全球保护等级。 |

## 产品与验证边界

来源结构新增 `abstract` 获取方式；中英文都明确显示“已读摘要，未读全文”。每条链接仍给具体支持范围和核对日期，未引入整物种 `verified` 标记。其他61物种仍未接入这套逐断言来源；首物种与七星瓢虫也都只是局部核校。

事实修正同步到详情、热点、课程、测验及构建生成的中英文静态物种页。数字中英一致性、字段长度和课程契约沿用现有测试；新增组件测试验证摘要获取标签和具体支持范围，不将单测当作事实核校。浏览器新增七星瓢虫中英320px来源区场景，检查四条链接、摘要标签、核对日期和横向溢出。

总述保留“血淋巴 / hemolymph”这一科学术语与实际防御说明，正文搜索仍能发现该物种；原搜索测试仅更新语料所在字段的注释，断言和搜索范围没有改变。

本地验证：131个测试文件、5,602项通过；生产构建与类型检查、照片署名一致性检查通过；20个Chromium场景通过。独立只读审核实际访问四条主来源并复查改后总述，未发现必须修复的问题。
