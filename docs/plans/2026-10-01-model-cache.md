# 模型缓存引用保护与阶段上限

目标：连续切换物种/生活史时缓存回落到稳定规模，当前展示、对比和离场模型不被逐出。保持模块预取、首屏实际模型预热、0.24秒离场动画和错误兜底。

实现顺序：
1. 共用模型缓存管理器，成虫和阶段各12项；同步取得加载引用，独立幂等释放；加载合并、失败重试；只逐出未被引用的最老条目，全被引用时允许暂时超限，释放后再次收缩。
2. 按模型独立几何/材质集合登记资源引用，最后一个缓存所有者逐出时释放一次；纹理由现有全局池持有，不跟模型释放。
3. Scene与调试台使用加载引用。请求取消及时释放未采用结果；已采用结果保留至React提交移除，离场过程也持有。卸载释放全部持有引用。
4. 测试延迟加载、失败/取消、多个消费者、全部被持有时超限、离场/快速切换、共享资源和真实阶段遍历。真实浏览器压力检查缓存与资源回落，同时跑既有布局/反馈回归。
5. 独立复审、完整检查后提交推送上线，核对正式域名和版本。

边界：12项是模型数量上限，不是字节预算；正在展示的对象可暂时让其超限。模块缓存仍由ES模块系统保留。本轮不扩大其余物种核校或Canvas分包范围。
